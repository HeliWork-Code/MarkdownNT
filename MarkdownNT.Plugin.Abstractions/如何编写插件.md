# 如何编写 MarkdownNT 插件

本文介绍如何使用 `MarkdownNT.Plugin.Abstractions` 编写一个 MarkdownNT
自定义语法插件。

## 1. 插件接口是什么

MarkdownNT 官方插件接口是一个可选的独立接口层：

```text
MarkdownNT.Plugin.Abstractions
```

它只提供插件接口和规则数据，不依赖：

- `MarkdownNT.Core`
- Avalonia
- AvaloniaEdit
- MarkdownNT Official Editor

因此，开发者可以选择使用官方接口，也可以自行设计插件系统。

当前插件接口版本：

```text
MarkdownNT.Plugin.Abstractions v1.1.0
``` 

当前核心库版本：

```text
MarkdownNT.Core v1.1.4
```

## 2. 创建插件项目

推荐创建一个 `netstandard2.0` 类库项目：

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>netstandard2.0</TargetFramework>
    <Nullable>enable</Nullable>
    <LangVersion>9.0</LangVersion>
  </PropertyGroup>

  <ItemGroup>
    <ProjectReference Include="..\MarkdownNT.Plugin.Abstractions\MarkdownNT.Plugin.Abstractions.csproj" />
  </ItemGroup>
</Project>
```

也可以直接引用编译生成的：

```text
MarkdownNT.Plugin.Abstractions.dll
```

插件项目不需要引用 `MarkdownNT.Core` 或 Avalonia。

## 3. 实现 IMdNTCode

插件需要实现 `IMdNTCode`：

```csharp
using MarkdownNT.Plugin.Abstractions;
using System;
using System.Collections.Generic;

public sealed class TodoPlugin : IMdNTCode
{
    public string Id => "example.todo";
    public string Name => "Todo 语法";
    public Version Version => new Version(1, 0, 0);

    public IEnumerable<MdNTCodeRule> GetRules()
    {
        yield return new MdNTCodeRule
        {
            Name = "TODO 关键词",
            Keyword = "TODO",
            Priority = 100,
            Style = new MdNTCodeStyle
            {
                Foreground = "#FF8800",
                Background = "#FFF0CC",
                Bold = true,
                Underline = true
            }
        };
    }
}
```

属性说明：

| 属性 | 作用 |
| --- | --- |
| `Id` | 插件唯一标识，建议使用反向域名格式 |
| `Name` | 插件显示名称 |
| `Version` | 插件自身版本 |
| `GetRules()` | 返回插件提供的规则 |

`Id` 应保持稳定，不要因为显示名称改变而修改。编辑器使用它保存插件启用或禁用状态。

## 4. 使用关键词匹配

`Keyword` 用于匹配固定文本：

```csharp
new MdNTCodeRule
{
    Name = "警告标记",
    Keyword = "WARNING",
    Priority = 10,
    Style = new MdNTCodeStyle
    {
        Foreground = "#CC0000",
        Bold = true
    }
}
```

文档中的所有匹配文本都会应用该规则：

```text
WARNING：请检查配置。
```

## 5. 使用正则表达式匹配

`Expression` 用于匹配一类文本：

```csharp
new MdNTCodeRule
{
    Name = "双中括号内容",
    Expression = @"\[\[(.*?)\]\]",
    Priority = 20,
    Style = new MdNTCodeStyle
    {
        Foreground = "#0066CC",
        Background = "#EAF4FF",
        Italic = true,
        Strikethrough = true
    }
}
```

它可以匹配：

```text
[[重要内容]]
[[参考资料]]
[[任意文本]]
```

关键词和正则表达式至少应设置一个。当前 Official Editor 对正则表达式设置了
100 毫秒执行超时；无效表达式或超时规则会被记录到日志。

## 6. 设置显示样式

`MdNTCodeStyle` 支持以下字段：

| 属性 | 作用 |
| --- | --- |
| `Foreground` | 亮色模式前景色 |
| `Background` | 亮色模式背景色 |
| `DarkForeground` | 暗色模式前景色 |
| `DarkBackground` | 暗色模式背景色 |
| `FontFamily` | 字体族名称 |
| `Bold` | 粗体 |
| `Italic` | 斜体 |
| `Underline` | 下划线 |
| `Strikethrough` | 删除线 |
| `Effect` | 效果名称，由宿主自行解释 |

颜色推荐使用十六进制格式，例如：

```text
#FF8800
#FFF0CC
#FFFFFF
```

暗色模式可以单独设置颜色：

```csharp
Style = new MdNTCodeStyle
{
    Foreground = "#0066CC",
    Background = "#EAF4FF",
    DarkForeground = "#72B7FF",
    DarkBackground = "#18324A",
    Italic = true
}
```

如果没有设置 `DarkForeground` 或 `DarkBackground`，Official Editor 会回退使用普通模式
的 `Foreground` 或 `Background`。

`Effect` 当前是可选的数据字段。不同宿主可以按照自己的方式解释它，Official Editor
当前不会因为该字段自动创建额外效果。

## 7. 设置规则优先级

`Priority` 数值越大，优先级越高：

```csharp
Priority = 100
```

当多个规则匹配到重叠文本时，Official Editor 优先使用优先级更高的规则；优先级相同
时按规则发现顺序处理。建议为范围更具体的规则设置更高优先级。

## 8. 构建和安装

构建插件：

```powershell
dotnet build -c Release
```

将插件 DLL 复制到 Official Editor 程序目录下的 `Plugins` 文件夹或其子目录：

```text
MarkdownNT\
├─ MarkdownNT.dll
├─ MarkdownNT.Plugin.Abstractions.dll
└─ Plugins\
   └─ YourPlugin\
      └─ YourPlugin.dll
```

编辑器启动时会扫描 `Plugins` 目录，并查找实现 `IMdNTCode` 的公开类型。
插件成功加载后，日志会记录：

```text
Plugin Done:your.plugin.id+1.0.0
```

## 9. 在测试文档中验证

创建一个 `.mdnt` 文件：

```text
# 插件测试

TODO：测试关键词样式。

[[测试正则表达式样式]]

普通文本继续显示。
```

重启编辑器后打开文件，观察预览区域中的颜色、背景、字体和文字装饰。
插件规则目前主要应用于普通段落预览，不会自动改变核心解析结果。

## 10. 当前限制

- 插件需要重启编辑器后加载，当前不支持运行时热加载。
- 当前官方宿主主要在普通段落预览中应用规则。
- 插件规则不会自动修改 MarkdownNT 核心解析器。
- `Effect` 字段由宿主解释，当前 Official Editor 不提供通用效果实现。
- C# DLL 插件可以执行本机代码，只应安装可信来源的插件。
- 插件加载失败不会阻止编辑器启动，具体错误会写入运行日志。

## 11. 版本和兼容性

插件自身版本与插件接口版本是两个概念：

```text
MarkdownNT.Plugin.Abstractions v1.1.0
YourPlugin v1.0.0
```

插件接口发生不兼容变化时才升级主版本。插件自身功能变化时，只升级插件自己的版本。

当前官方组件：

```text
MarkdownNT.Core v1.1.4
MarkdownNT.Plugin.Abstractions v1.1.0
MarkdownNT Official Editor v1.1.4
```

MarkdownNT 的官方插件接口是可选方案。开发者可以使用它，也可以为自己的编辑器
设计其他插件接口。
