# MarkdownNT.Lab

MarkdownNT.Lab 是一个面向 MarkdownNT 插件开发的图形化实验应用，目标是让插件编写更简单、更可视化、更快速迭代。

## 目标

- 快速测试插件规则
- 扫描并加载插件 DLL
- 让开发者在本地快速验证关键词和正则匹配
- 提供插件模板生成器，减少重复代码
- 以可视化界面展示测试结果和插件管理状态

## 当前状态

当前版本已经升级为一个最小 GUI 版本，包含：

- 测试文本编辑区
- 插件加载按钮
- 规则测试按钮
- 结果列表面板
- 插件模板生成器

后续可继续扩展为：

- 规则可视化编辑器
- 语法预览器
- 主题切换
- 热重载插件
- 插件工程模板向导

## 使用方式

在项目目录中执行：

```powershell
dotnet run --project MarkdownNT.Lab.csproj
```

## 特色

- 内置 DemoPlugin
- 规则命中测试
- GUI 结果展示
- 生成插件模板脚本
- 为后续开发保留扩展点
